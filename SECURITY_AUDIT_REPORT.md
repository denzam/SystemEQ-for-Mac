# 🔒 Аудит безпеки SystemEQ for Mac

**Дата аудиту:** 28 січня 2026  
**Версія:** 1.0  
**Аудитор:** Cascade AI

---

## 📊 Загальна оцінка: ✅ БЕЗПЕЧНО

SystemEQ for Mac є **безпечним для кінцевого користувача**. Додаток не збирає персональні дані, не має прихованих мережевих з'єднань і працює локально.

---

## 🟢 Позитивні аспекти безпеки

### 1. Відсутність збору персональних даних
- ❌ **Немає телеметрії** - додаток не відправляє жодних даних на зовнішні сервери
- ❌ **Немає аналітики** - не використовується Google Analytics, Firebase, Mixpanel тощо
- ❌ **Немає реєстрації** - не потрібен обліковий запис для використання

### 2. Локальне зберігання даних
Всі дані зберігаються **виключно локально** на комп'ютері користувача:

| Тип даних | Місце зберігання | Чутливість |
|-----------|------------------|------------|
| EQ налаштування | `UserDefaults` | Низька |
| Персоналізовані профілі | `~/Library/Application Support/SystemEQ for Mac/` | Низька |
| Кеш AutoEQ індексу | `~/Library/Application Support/SystemEQ/` | Низька |
| Обрані пресети | `@AppStorage` (UserDefaults) | Низька |

### 3. Мережева активність
Додаток робить **мінімальні** мережеві запити:

| Endpoint | Призначення | Частота |
|----------|-------------|---------|
| `raw.githubusercontent.com/jaakkopasanen/AutoEq` | Завантаження індексу AutoEQ | При оновленні (раз на місяць) |
| `api.github.com/repos/jaakkopasanen/AutoEq` | Перевірка оновлень бази | При ручному запиті |

**Важливо:** 
- ✅ Всі запити йдуть на публічні репозиторії GitHub
- ✅ Немає API ключів або секретів
- ✅ Локальна SQLite база (17 MB) працює 100% офлайн

### 4. Дозволи (Permissions)

| Дозвіл | Причина | Ризик |
|--------|---------|-------|
| **Microphone Access** | Захоплення системного звуку через BlackHole (НЕ фізичний мікрофон) | Низький |
| **Accessibility** | Перехоплення медіа-клавіш (F10/F11/F12) для керування гучністю | Низький |

**Пояснення для користувача:**
- Мікрофонний доступ потрібен для Core Audio API, але фактично записується тільки віртуальний аудіо-потік з BlackHole
- Accessibility потрібен тільки для медіа-клавіш, можна не надавати якщо не потрібно

### 5. Sandbox статус
```
ENABLE_APP_SANDBOX = NO
```
- Додаток працює **без Sandbox** для доступу до Core Audio API
- Це необхідно для системного аудіо-обробки
- Не є проблемою безпеки для цього типу додатків

### 6. Логування
- ✅ Всі debug-логи видаляються в Release build (`#if DEBUG`)
- ✅ Функції `dlog()`, `audioLog()`, `errorLog()` компілюються в порожні функції
- ✅ Жодна чутлива інформація не логується

## 🟡 Рекомендації — ✅ ВИКОНАНО

### 1. ✅ fatalError() в EQDatabase.swift — ВИПРАВЛЕНО
**Було:** `fatalError()` призводив до крашу додатку якщо база даних відсутня.

**Зроблено:** Замінено на graceful degradation з `dlog()`:
- Додано властивість `isAvailable` для перевірки доступності бази
- Додаток продовжує працювати навіть без бази даних (AutoEQ функції просто вимкнені)

### 2. ✅ print() в Release build — ВИПРАВЛЕНО
**Було:** 259 викликів `print()` залишались в Release build.

**Зроблено:** Всі `print()` замінено на `dlog()`:
- В Release build всі логи автоматично видаляються компілятором
- Нульовий overhead в production
- Файли оновлені: AudioRouter, CoreAudioEngine, AutoEQView, CalibrationEngine, VisualizerEngine, WindowTitleManager, LocalizationManager та інші

### 3. URLSession кешування
**Файл:** `@/Users/denyszamorniak/CascadeProjects/SystemEQ for Mac/SystemEQ for Mac/Features/AutoEQView.swift:110-121`

```swift
config.urlCache = URLCache(
    memoryCapacity: 50 * 1024 * 1024,  // 50 MB в пам'яті
    diskCapacity: 100 * 1024 * 1024,   // 100 MB на диску
    directory: nil

```

**Примітка:** Кеш зберігається в стандартній директорії системи. Це нормально, але варто документувати для користувачів.

## 🔴 Критичні проблеми: ВІДСУТНІ

Не виявлено жодних критичних проблем безпеки:
- ❌ Немає hardcoded API ключів або секретів
- ❌ Немає SQL injection (використовується prepared statements)
- ❌ Немає виконання довільного коду (eval, exec, NSAppleScript)
- ❌ Немає небезпечних файлових операцій
- ❌ Немає передачі даних третім сторонам
