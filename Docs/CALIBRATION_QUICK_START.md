# 🎧 Калібрація на слух - Quick Start

## За 5 хвилин до ідеального звуку!

### Крок 1: Відкрий Calibration

```
Main Window → Calibration button
```

### Крок 2: Вибери режим

**Clean Calibration (Рекомендовано)**
- Калібрує чисті навушники без EQ
- Найточніший результат

### Крок 3: Вибери кількість смуг

**10 Bands (Рекомендовано)**
- 5 хвилин
- 90% точності
- Ідеально для початку

**31 Bands (Для перфекціоністів)**
- 15 хвилин
- 100% точності
- Потребує терпіння

### Крок 4: Встанови референс

1. Натисни **Play Reference** (1000 Hz)
2. Регулюй слайдер до комфортної гучності
3. Запам'ятай цей рівень
4. Натисни **Continue to Calibration**

### Крок 5: Калібруй частоти

**Для кожної частоти:**

1. **Вибери тип сигналу:**
   - 🎵 **Pink Noise** (рекомендовано) - природніше, легше оцінити
   - 🎼 **Pure Tone** - класичний метод

2. **Слухай і порівнюй:**
   - Натисни **Play Reference** (1000 Hz)
   - Натисни **Play Test** (поточна частота)
   - Або **Compare** для автоматичного чергування

3. **Регулюй слайдер:**
   - Якщо тестова частота **тихіша** → тягни вправо (+dB)
   - Якщо **голосніша** → тягни вліво (-dB)
   - Мета: обидві частоти звучать **однаково голосно**

4. **Натисни Next** → наступна частота

### Крок 6: Збережи профіль

1. Після останньої частоти → **Save Profile**
2. Введи назву (наприклад: "Sony WH-1000XM4 + My Room")
3. Додай нотатки (опціонально)
4. **Save**

### Крок 7: Активуй профіль

```
Calibration → Profiles tab → Activate
```

Готово! 🎉

## 💡 Поради

### Для найкращого результату:

✅ **Тихе середовище** - вимкни вентилятори, закрий вікна
✅ **Комфортна гучність** - не занадто голосно!
✅ **Відпочинь** - не калібруй втомленим
✅ **Не поспішай** - краще 10 хвилин якісно, ніж 5 хвилин абияк
✅ **Використовуй Pink Noise** - легше оцінити баланс

### Якщо втомився:

⏸️ Натисни **Back to Reference**
☕ Зроби перерву 5-10 хвилин
▶️ Продовж з того місця

### Якщо не впевнений:

🔄 Використовуй кнопку **Compare (Alternating)**
- Автоматично чергує reference і test
- Легше порівняти

## 🎯 Що очікувати?

### Після калібрації:

✨ **Збалансований звук** - всі частоти чуються рівномірно
🎵 **Більше деталей** - чуєш те, що раніше пропускав
🎧 **Менше втоми** - навушники не "тиснуть" на певних частотах
🏠 **Компенсація кімнати** - резонанси та поглинання враховані

### Тестуй на музиці:

- **Вокал** - чіткіший, природніший
- **Бас** - контрольований, не гуркотить
- **Високі** - деталізовані, не різкі
- **Інструменти** - кожен чути окремо

## 🔧 Troubleshooting

### "Не чую різниці між частотами"

→ Збільш гучність референсу
→ Використовуй Pure Tone замість Pink Noise
→ Зроби перерву, відпочинь вуха

### "Занадто довго калібрувати 31 смугу"

→ Почни з 10 смуг
→ Роби перерви кожні 10 частот
→ Можна зберегти проміжний результат

### "Результат звучить дивно"

→ Перевір, чи активований правильний профіль
→ Спробуй A/B порівняння (Profiles → A/B Compare)
→ Можна підстроїти окремі смуги

## 📊 Приклад результату

**До калібрації:**
```
31 Hz:   0 dB  (гуркіт)
125 Hz:  0 dB  (мутний бас)
1000 Hz: 0 dB  (референс)
4000 Hz: 0 dB  (різкі високі)
16000 Hz: 0 dB (не чути)
```

**Після калібрації:**
```
31 Hz:   +8 dB  (тепер чути!)
125 Hz:  +3 dB  (чіткий бас)
1000 Hz:  0 dB  (референс)
4000 Hz: -5 dB  (м'які високі)
16000 Hz: +6 dB (деталі повернулись)
```

## 🎓 Наступні кроки

1. **Тестуй на різній музиці** - різні жанри
2. **Створи кілька профілів** - для різних навушників
3. **Використовуй A/B Compare** - порівнюй профілі
4. **Підстроюй при потребі** - можна змінити окремі смуги
