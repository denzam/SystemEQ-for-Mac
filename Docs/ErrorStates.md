# Error & Empty States (Copy Guidelines)

- AutoEQ import failed: "Could not parse this file. Supported: ParametricEQ.txt, GraphicEQ."
- Unsupported filter type: "Filter X ignored (type not supported)."
- Excess filters for 10-band: "Profile reduced to 10 bands; see approximation report."
- BlackHole missing: "BlackHole not detected. Open guide to install."
- Sample rate mismatch: "Devices have different sample rates. Set both to 48 kHz."
- Mic permission missing: "Microphone access required for calibration."
