# Accessibility & Localization

- Languages: EN, UKR (start with EN; add UKR strings early).
- Contrast: adhere to WCAG AA equivalent.
- VoiceOver: label controls (band freq, gain, Q), stateful toggles (ON/OFF).
- Keyboard: shortcuts for toggles, preset switching.
- Units: show Hz/dB/Q consistently; localize decimal separators.
