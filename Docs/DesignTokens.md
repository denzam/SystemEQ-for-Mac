# Design Tokens (Foundation)

Note: final "Liquid Glass" polish later. Use system semantics first.

## Colors (semantic)
- `bg.window` = NSColor.windowBackgroundColor
- `bg.popover` = NSColor.underPageBackgroundColor
- `fg.primary` = labelColor; `fg.secondary` = secondaryLabelColor
- `accent` = controlAccentColor
- `meter.clip` = systemRed

## Typography
- SF Pro; sizes: 11, 13, 15, 17, 20, 28 (Title/Heading/Body/Caption)

## Radii & Effects
- Radius: 8, 12
- Shadow: subtle for floating panels
- Blur: material-like (later for Liquid Glass)

## Spacing
- 4, 8, 12, 16, 24, 32
