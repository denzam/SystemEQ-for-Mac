# Onboarding — MVP (BlackHole Routing)

## Steps
1) Install BlackHole (2ch is enough for MVP).
2) Open Audio MIDI Setup → Create Multi-Output Device (BlackHole + your output).
3) Set Multi-Output as system output device (Sound settings).
4) In app: select BlackHole as input device; hardware as output.
5) Play audio and adjust EQ; check meters and clipping.

## Permissions
- Microphone: required for calibration wizard.
- Accessibility/Screen Recording: only if screen-capture audio route is used (not in MVP).
